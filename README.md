# Jekyll + Markdown version of your homepage

## Files
- `index.md` — the main content you will edit most of the time
- `_layouts/default.html` — page shell (header, nav, structure)
- `assets/css/style.css` — styling
- `_config.yml` — Jekyll config

## How to use on GitHub Pages
1. Copy these files into the root of your GitHub Pages repository.
2. Also keep your existing `CV_hwr.pdf` and `wenrui2.png` in the repository root.
3. Commit and push.
4. In GitHub repository settings, make sure Pages is enabled for your main branch.

## What you edit later
Usually only `index.md`.
